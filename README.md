This program writes one short poem about agency — the power to ask and to be given — and runs offline with the Python standard library only.

## Run it

```sh
python3 main.py
```

It writes to `/output/entry.txt`. Setting the `MAKEFUN_OUTPUT_DIR` environment variable redirects the output elsewhere.
